# ユーザーテスト計画書

プロジェクト: Life in Weeks  
作成日: 2026年8月6日  
テスト対象バージョン: 1.0.0（TestFlight配信版）

---

## 1. テストの目的

| 目的 | 検証する仮説 |
|------|------------|
| オンボーディング完了率の確認 | 初回起動から生年月日入力→グリッド表示まで、ヒントなしで完了できるか |
| コア機能の発見性検証 | 週次★記録・統計確認・壁紙設定をユーザーが自力で発見・操作できるか |
| KPI達成可能性の事前検証 | 初回記録完了率60%・継続意向40%の目標が現実的かを定性的に確認 |
| 致命的UX問題の発見 | リリース前に修正すべきCritical問題を洗い出す |

---

## 2. テスト対象フロー

| 優先度 | フロー | 対応機能要件 |
|--------|--------|------------|
| 必須 | オンボーディング（O01→O02→O03）→初回グリッド表示 | 2.1〜2.2 |
| 必須 | 今週の★評価記録（FABタップ→★3入力→保存） | 2.3 |
| 通常 | 人生消費率・統計確認（統計タブ） | 2.4 |
| 通常 | 壁紙自動更新の設定（O02またはSettingsから） | 2.5 |
| 任意 | 設定変更（想定寿命・カテゴリー変更） | 2.6〜2.7 |

---

## 3. 参加者要件

| 項目 | 条件 |
|------|------|
| 人数 | 5名以上（ニールセンの法則：5名で80%の問題を発見） |
| 年齢 | 20〜40代 |
| デバイス | iPhone（iOS 17以上）所持者 |
| 経験 | 習慣管理アプリ（Habitica・Streaks・Notion等）の使用経験あり、または目標管理に関心がある |
| 除外条件 | アプリ開発者・UI/UXデザイナー（バイアスが強いため） |

**募集チャネル**: Shogoの知人・Twitterフォロワー・社内有志  
**謝礼**: なし（感謝のメッセージのみ）  
**実施形態**: 対面またはZoom画面共有（録画あり・同意取得済みの場合）

---

## 4. テスト環境

| 項目 | 内容 |
|------|------|
| 配信方法 | TestFlight（招待コード発行） |
| デバイス | 参加者自身のiPhone（持ち込み） |
| データ状態 | 未使用の状態（初回起動から開始） |
| 観察環境 | 対面: 隣に座って観察 / オンライン: Zoom画面共有 |
| 記録方法 | 観察記録シート（participants/observation-sheet.md） |

## 5. スケジュール

| 作業 | 時期 | 担当 |
|------|------|------|
| TestFlight配信準備 | App Store申請後 | Shogo |
| 参加者募集・招待コード発行 | TestFlight承認後 | Shogo |
| テスト実施（1人あたり30〜45分） | 参加者との日程調整 | Shogo（ファシリテーター） |
| 結果集計・レポート作成 | 全員完了後1週間以内 | Shogo |
| Critical問題の修正 | レポート完了後 | Shogo + Claude |

---

## 6. 合否判定基準

| 指標 | 合格ライン | 根拠 |
|------|----------|------|
| 必須タスク完了率 | 70%以上 | 初回記録完了率目標60%から逆算 |
| SUSスコア（System Usability Scale） | 68点以上 | 業界平均（合格水準） |
| Critical問題件数 | 0件 | リリースブロッカー条件 |
| 継続利用意向（4段階: 絶対使う/使いそう/使わなさそう/絶対使わない） | 「使いそう」以上が5名中3名以上 | 4週継続率目標40%の先行指標 |

---

## 7. SUSアンケート（10問・5段階評価）

テスト終了後、参加者に以下のアンケートを実施する。

| No. | 設問 |
|-----|------|
| 1 | このアプリを頻繁に使いたいと思う |
| 2 | このアプリは複雑だと感じた |
| 3 | このアプリは使いやすいと感じた |
| 4 | このアプリを使うためにサポートが必要だと感じた |
| 5 | このアプリの各機能はよく統合されていると感じた |
| 6 | このアプリには一貫性がないと感じた |
| 7 | 多くの人がこのアプリをすぐに使えると思う |
| 8 | このアプリはとても使いにくいと感じた |
| 9 | このアプリを使う自信があると感じた |
| 10 | このアプリを使い始める前に多くのことを学ぶ必要があった |

**採点方式**: 奇数問は（回答-1）、偶数問は（5-回答）、合計×2.5 = 100点満点

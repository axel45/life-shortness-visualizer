# ドット配色 改善案（フィードバック #1 対応）

問題: 過去の未記録週（白丸）と未来の週（グレー丸）が黒背景で見分けにくい

---

## 案A: 中抜き vs 塗りつぶし（推奨）

未来の週を「輪郭のみ（中抜き）」にして、過去の未記録週との違いを形で表現。

```
黒背景上のドット表現:

未来の週     ○  ← アウトラインのみ (#8E8E93 ストローク、塗りなし)
未記録の過去  ●  ← 白 (#FFFFFF) 塗りつぶし
記録あり(低)  ●  ← 薄い赤 (#FFD5CC)
記録あり(普)  ●  ← 白 (#FFFFFF)
記録あり(高)  ●  ← 銀色
記録あり(全5) ●  ← 金色
今週（現在）  ●  ← 黄色リング（選択状態インジケーター）
```

**変更内容**
- 未来: `fill: .clear, stroke: #8E8E93` に変更（中抜き円）
- 未記録過去: `fill: #FFFFFF` に変更（現行の#F2F2F7から白に強調）

**メリット**: 形が変わるので色覚の違いに関わらず区別可能。「未来＝まだ塗られていない」が視覚的に伝わる。

---

## 案B: 濃度差を強調

未来を濃いグレー、未記録過去を白にしてコントラストを上げる。

```
黒背景上のドット表現:

未来の週     ●  ← 濃いグレー (#636366)
未記録の過去  ●  ← 白 (#FFFFFF)
```

**変更内容**
- 未来: `#D1D1D6` → `#636366`（より暗いグレー）
- 未記録過去: `#F2F2F7` → `#FFFFFF`（純白に変更）

**メリット**: コード変更が最小限。色だけの変更。

---

## 案C: サイズ差

未来のドットを小さくして「まだ来ていない」を表現。

```
黒背景上のドット表現:

未来の週     · ← 60%サイズ (#D1D1D6)
未記録の過去  ● ← 通常サイズ (#FFFFFF)
```

**変更内容**
- 未来: `dotSize × 0.6` で描画
- 未記録過去: `#F2F2F7` → `#FFFFFF`

**メリット**: 密度の差で「未来感」が出る。ただし画面がまばらに見える。

---

## 推奨: 案A（中抜き）

視覚的な区別が最も明確で、意味的にも「未来＝空白」を直感的に表現。

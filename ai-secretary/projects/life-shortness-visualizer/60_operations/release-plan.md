## 2. ロールバック手順

本アプリはサーバーレス構成のため、「ロールバック = 旧バージョンの再申請」となる。

### App Store ロールバック
```
1. App Store Connect > ビルド > 旧バージョンのビルドを選択
2. 「このバージョンで申請」を実行
3. Appleの審査（通常1〜3営業日）通過後、旧バージョンが公開される
```

### データロールバック（ユーザー側）
- SwiftData + CloudKit の構成のためアプリ側でのデータロールバックは不可
- スキーマ破壊的変更を行った場合: `VersionedSchema` で移行済みデータを保持（db_design.md 8.マイグレーション方針参照）
- **緊急手順**: v1.0.0 のスキーマ変更は最小限に保ち、破壊的変更は v2.0.0 まで持ち越す

### 障害レベル定義

| レベル | 内容 | 対応時間目安 |
|-------|------|------------|
| P0 | アプリがクラッシュして起動不能 | 即座にApp Storeで非公開化 → 修正版を緊急申請 |
| P1 | データが消える・保存されない | 24時間以内に修正版を申請 |
| P2 | 特定機能が動作しない（壁紙生成など） | 1週間以内に修正版を申請 |
| P3 | UI表示のズレ・軽微な不具合 | 次回定期アップデートで対応 |

**エスカレーションフロー（個人開発のため Shogo が単独対応）**
```
ユーザーレビュー / クラッシュレポート（App Store Connect）
  ↓ 確認
Xcode Organizer > Crashes でクラッシュログを確認
  ↓ 原因特定
修正 → Archive → App Store 申請
```

## 3. 監視・アラート設計

### 監視対象（App Store Connect + CloudKit Dashboard）

| 監視項目 | ツール | 確認タイミング |
|---------|-------|-------------|
| クラッシュレート | App Store Connect > Crashes | リリース後1週間は毎日 |
| App Store レビュー | App Store Connect > レビュー | 週1回 |
| CloudKit Storage 使用量 | CloudKit Dashboard | 月1回 |
| KPI: 4週継続率 | WeekRecord.createdAt から手動集計 | リリース4週後 |
| KPI: 初回記録完了率 | onboardingCompletedAt vs WeekRecord作成日 | リリース1週後 |

### アラート条件
- App Store Connect のクラッシュ通知をメール受信設定する
- クラッシュレートが 1% を超えたら P0 対応を開始
- レビュー評価が 3.0 を下回ったら機能改善を優先

- アプリ側でのバックアップ作業不要

## 5. App Store 申請情報

### アプリ説明文（日本語）
```
人生80年を4,160個の丸で可視化するアプリ。

あなたはいま、人生の何週目にいますか？

Life in Weeksは、生年月日を入力するだけで
人生全体のグリッドをホーム画面の壁紙として毎週自動更新します。

【主な機能】
• 人生グリッド — 80年分の4,160週を一覧表示
• 週次記録 — 運動・食事・睡眠などを★1〜5で評価
• 統計 — カテゴリー別グラフとストリーク
• 壁紙自動更新 — ショートカットAppで毎週月曜に自動設定
• iCloud同期 — 複数デバイスで記録を共有

【プライバシー】
データはデバイス内とiCloudのみに保存します。
外部サーバーへの送信は一切ありません。
```

### キーワード（100文字以内）
```
人生,可視化,習慣,目標管理,グリッド,壁紙,週次,ライフスタイル,振り返り,iCloud
```

### プライバシーポリシー
```
収集するデータ: 生年月日、週次評価記録（ローカル + iCloudのみ）
外部送信: なし
写真ライブラリ: 壁紙保存のみに使用（読み取りなし）
通知: ユーザーが許可した場合のみ週次リマインダーを送信
```

### スクリーンショット構成（必要な3枚）
1. グリッド画面（S01）— 人生全体が一目でわかる
2. 週詳細シート（S02）— ★評価の記録UI
3. ホーム画面壁紙（W02）— 実際の壁紙イメージ

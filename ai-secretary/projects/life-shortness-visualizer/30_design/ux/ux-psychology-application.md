## 全画面共通の設計方針

### 感情デザイン（3層モデル）の適用方針

| 層 | 目指す感情 | 主な実装手段 |
|----|-----------|------------|
| 本能（Visceral） | 静けさ・重厚感・誠実さ | 黒背景・金銀白の丸・SF Pro フォント・静かなフェードイン |
| 行動（Behavioral） | 確かな手応え・スムーズさ | ハプティクス・即時フィードバック・0.4秒以内の描画 |
| 内省（Reflective） | 「自分の時間を大切にしている」自己肯定感 | 丸の積み上げ・ポジティブなコピー・節目の特別演出 |

### カラーパレット（確定）


## O01 生年月日入力画面

### 適用法則と実装

| 法則 | 実装内容 |
|------|---------|
| 段階的要請（Foot in the Door） | オンボーディングの最初は「生年月日を入力するだけ」という最小のお願いにとどめる |
| ポステルの法則 | 数字のみ入力させ、フォーマット（YYYY/MM/DD）はアプリが整形して表示する |
| テスラーの法則 | 「今週が何週目か」の計算はアプリが行う。ユーザーが入力するのは生年月日のみ |
| Z字視線パターン | 左上にアプリロゴ、右下に「次へ」ボタンを配置 |
| フィッツの法則 | 「次へ」ボタンは44pt以上・画面下部に配置 |
| 好奇心ギャップ | 入力前に「あなたの人生は4,160個の丸でできています」と表示してから入力を促す |

### マイクロコピー

```
NG: 「生年月日を入力してください」
OK: 「あなたが生まれた日を教えてください。
     そこから、あなただけの人生グリッドが作られます。」

NG: 「次へ」
OK: 「グリッドを作る」
```

### 実装チェックリスト

- [ ] 数字入力後に YYYY年MM月DD日 と自動整形される
- [ ] 未来の日付・存在しない日付はリアルタイムでエラー表示（赤ではなくオレンジで穏やかに）
- [ ] 「次へ」ボタンは生年月日が有効な場合のみ活性化
- [ ] キーボードは数字キーパッドを使用

## O02 壁紙設定ガイド画面

### 適用法則と実装

| 法則 | 実装内容 |
|------|---------|
| 段階的開示 | ショートカットの設定手順を1ステップずつ表示。全手順を一度に見せない |
| ヒックの法則 | 各ステップで選択肢は1つ（「次のステップへ」のみ）。スキップは控えめに |

| ピーク・エンドの法則 | 設定完了時に「準備完了！毎週月曜日に壁紙が自動更新されます」と達成感を演出（エンド） |

### 実装チェックリスト

- [ ] 各ステップは1画面1操作
- [ ] 「あとで設定する」はテキストリンク形式で目立たせすぎない（デフォルト効果）
- [ ] 完了画面では軽いハプティクス（`.notificationFeedback(.success)`）を発火

## S01 グリッド画面（メイン）

### レイアウトへの適用

#### 視覚的階層
```
[最重要] 現在地の丸（赤・他の丸より一回り大きく）
[重要]   金色・銀色の丸（達成した過去）
[通常]   白・グレーの丸（過去の記録）
[背景]   黒丸・枠線のみ（未来）
[補助]   ライフステージバー（左端）
[情報]   下部統計バー（底部）
```

#### Gestalt原則の適用
- **近接**: ライフステージバーと対応する行のグリッドは視覚的に近くに配置
- **類似**: 同じ状態の丸は同じ色で統一（金・銀・白・グレー・黒）
- **図と地**: 現在地（赤丸）が図、他の丸が地になるよう輝度差をつける
- **連続**: 過去から未来へ左→右・上→下の自然な時間の流れ

### インタラクション設計

| 操作 | 法則 | 実装内容 |
|------|------|---------|
| タップ（丸） | フィッツの法則 | 視覚サイズより大きいタップ領域（最小44pt）。Canvas描画でhitTest別途実装 |
| スワイプ（左右） | ヤコブの法則 | 週移動は標準的なスワイプジェスチャー |
| スワイプ（上下） | ヤコブの法則 | 年移動は縦スクロールの標準動作に準拠 |
| 現在週へ戻るボタン | 損失回避 | 「今週を見る」ボタン。記録忘れ防止のアンカーとして機能 |

### パフォーマンス（ドハティの閾値）
- Canvas で4,160個の丸を一括描画（個別ビューは使わない）
- 初回描画は0.4秒以内を目標
- 超える場合はスケルトンスクリーン（丸のシルエット）を表示してから本描画

### 視線誘導
- グリッドはF字パターンを想定（上部・左側を重視）
- 現在地（赤丸）はグリッドの中央付近に自動スクロールして表示
- 下部統計バーはZ字パターンの終点（右下）に重要な数値を配置

### マイクロコピー（下部統計バー）

```
NG: 「残り人生58年 / 人生消費率31.9%」
OK: 「まだ 58年 ある  ·  これまでの人生 31.9%」
```

### 実装チェックリスト

- [ ] Canvas 描画で4,160個の丸がスムーズにレンダリングされる
- [ ] 現在地の赤丸は起動時に画面中央に自動スクロール
- [ ] 過去週タップ → 週詳細シート（S02）がスライドアップ
- [ ] ライフステージバータップ → 統計シート（S03）がスライドアップ
- [ ] 下部コピーは「まだ〜ある」のポジティブフレーミング
- [ ] 画面描画は0.4秒以内（またはスケルトン表示）

## S02 週詳細シート（ボトムシート）

### 適用法則と実装

| 法則 | 実装内容 |
|------|---------|
| 認知負荷 | 1シートに表示するのは「週の期間 + カテゴリー別★評価 + 丸のカラープレビュー」の3要素のみ |
| 近接（Gestalt） | カテゴリー名と★評価を近接して配置。カテゴリー間は十分な余白で分離 |
| フィッツの法則 | ★評価は44pt以上のタップ領域。★同士の間隔を広めにとる |
| ハプティクス | ★をタップするたびに `.impactFeedback(.light)` を発火 |
| 保存時フィードバック | 保存完了時に `.notificationFeedback(.success)` + チェックマークアニメーション（ピーク・エンドの法則） |
| 目標勾配効果 | カテゴリー達成率のプレビュー（丸の色）をリアルタイムで表示。「全★5にするとあと○カテゴリー」を小さく表示 |
| ツァイガルニク効果 | 未入力のカテゴリーをプレースホルダー（○○○○○）で可視化し、入力欲求を促す |

### マイクロコピー

```
NG: 「記録を保存しました」
OK: チェックマークアニメーション のみ（言葉不要）

NG: 「カテゴリーを評価してください」
OK: 「今週の○○はどうでしたか？」（カテゴリー名を使う）

未入力状態:
NG: 「未記録」
OK: 「☆☆☆☆☆」（グレーの星で入力を促す）
```

### 実装チェックリスト

- [ ] ★入力のたびにハプティクス発火
- [ ] 全カテゴリー入力後に丸のカラープレビューがリアルタイム更新
- [ ] 保存時に成功フィードバック（ハプティクス + アニメーション）
- [ ] 下スワイプまたは背景タップで閉じる（ヤコブの法則）
- [ ] 過去週の記録閲覧・編集どちらも同一シートで対応

## S03 統計シート（ボトムシート）

### 適用法則と実装

| 法則 | 実装内容 |
|------|---------|
| サンクコスト効果 | 「あなたはこれまで○週間記録を続けてきました」という実績を冒頭に表示 |
| 目標勾配効果 | 連続達成週数（ストリーク）を大きく表示。「今週記録すると○週連続」を強調 |
| 系列位置効果 | 最も重要な統計（ストリーク数・全体達成率）をリストの先頭に配置 |
| 視覚的階層 | ストリーク数 > カテゴリー別グラフ > ライフステージ別サマリー の順で重要度を視覚化 |
| ピーク・エンドの法則 | 最高ストリーク記録を破った週には特別なバッジ（ピーク体験） |

### 実装チェックリスト

- [ ] 冒頭に「○週間の記録があります」の実績表示
- [ ] ストリーク数は最も大きいフォントサイズで表示
- [ ] Swift Charts のグラフはカテゴリー別に色分け（最大5色、視覚的に区別可能な配色）
- [ ] グラフのアニメーション: 0.3〜0.5秒の easeInOut

## S04 設定画面

### 適用法則と実装

| 法則 | 実装内容 |
|------|---------|
| ヤコブの法則 | iOS 標準の設定画面スタイル（リスト形式・グルーピング・ナビゲーション）を踏襲 |
| F字視線パターン | 重要な設定（生年月日・想定寿命）をリスト先頭に配置 |
| 系列位置効果 | セクションの順序: プロフィール → カテゴリー → ライフステージ → 壁紙ガイド → その他 |
| 意図的な壁 | データ全削除・リセット操作は最下部に配置 + 確認ダイアログ必須 |
| 認知負荷 | セクションは5個以内に収める（ヒックの法則も兼ねる） |

### 実装チェックリスト

- [ ] iOS標準のリストスタイルを使用（`List` + `Section`）
- [ ] 「データを全削除」は赤テキストで最下部に配置
- [ ] 全削除確認ダイアログのコピー: 「すべての記録が消えます。元に戻せません。」
- [ ] Dynamic Type 対応（テキストサイズを尊重）

## 全画面共通 実装チェックリスト

### パフォーマンス（ドハティの閾値）
- [ ] 画面描画・データ取得は0.4秒以内
- [ ] 超える場合はスケルトンスクリーンを表示
- [ ] UIスレッドをブロックしない（重い処理はバックグラウンドで）

### アクセシビリティ
- [ ] コントラスト比 4.5:1 以上（全テキスト）
- [ ] Dynamic Type 対応
- [ ] VoiceOver 対応（グリッドの各丸に `accessibilityLabel` を設定）
- [ ] Reduce Motion 対応（アニメーションをフェードに切り替え）
- [ ] ハプティクスはシステムの設定に従う

### コピーライティング
- [ ] ネガティブ表現 → ポジティブフレーミングに書き換え
- [ ] 空の状態（Empty State）は機会として表現
- [ ] エラーメッセージは「どうすれば直せるか」を含む

### ハプティクス
- [ ] ★評価タップ: `.impactFeedback(.light)`
- [ ] 記録保存: `.notificationFeedback(.success)`
- [ ] ストリーク記録更新: `.notificationFeedback(.success)` + 特別アニメーション
- [ ] 削除確認: `.impactFeedback(.heavy)`
- [ ] エラー: `.notificationFeedback(.error)`

## 年次・節目の特別演出（ユーザー歓喜効果）

以下のタイミングで通常と異なる演出を入れ、長期利用の「ピーク体験」を作る。

| タイミング | 演出内容 |
|-----------|---------|
| 誕生週（毎年） | 誕生週の丸に輝きエフェクト + 「お誕生日おめでとう。また1年、生きました。」 |
| ライフステージ移行 | 移行週に「新しいステージが始まりました」のバナー（1度だけ） |
| ストリーク記録更新 | 金色のバッジアニメーション + 「新記録達成！」 |
| 全★5週達成 | 丸が輝くアニメーション（通常の金色より演出強め） |
| 年末最終週 | 「今年の振り返り」サマリーを自動表示（金週・銀週の数） |
| 1,000週目 | 「人生1,000週目を迎えました」の特別メッセージ |

## 2. ナビゲーション構造

v1.0 の「歯車アイコン＋ライフステージバータップ」を廃止し、**タブバー** に統一する。

```
┌─────────────────────────────────┐
│                                 │
│         コンテンツエリア          │
│                                 │
├─────────────────────────────────┤
│ [カレンダー] [記録] [統計] [設定] │  ← タブバー（4タブ）
└─────────────────────────────────┘
```

**「記録」タブの実装（v3-#5）**
「記録」タブは通常のタブ画面ではなく、カレンダータブを維持したまま `WeekDetailSheet` をボトムシートとして表示する。
`TabView(selection:)` の `.onChange` でタブ1の選択を検知 → タブ0に戻す + `isRecordSheetPresented = true`。
シートはスワイプまたはタブ外タップで閉じる。`.presentationDetents([.medium, .large])` でハーフ表示対応。

**変更理由（ヤコブの法則）**
iOS ユーザーはタブバーによるナビゲーションに慣れている。
統計をライフステージバーのタップに隠すと発見されない。

## 3. オンボーディングフロー

### 概要

```
初回起動
 └─→ O00 スプラッシュ・アプリ紹介（自動進行 2秒）
       └─→ O01 生年月日入力（必須）
             └─→ O01.5 グリッド生成アニメーション（ピーク体験）
                   └─→ O02 カテゴリー設定（スキップ可）
                         └─→ S01 グリッド画面（メイン）
                               └─→ O03 壁紙設定ガイド（初回のみバナーで案内、タップで表示）
```

### O00 スプラッシュ・アプリ紹介（新規）

**目的**: 本能レベルの感情設計。アプリのトーンを最初の5秒で伝える。

```
┌─────────────────────────────────┐
│                                 │
│                                 │
│    ● ● ● ● ● ● ● ● ●          │
│    ● ● ● ● ● ● ● ● ●          │  ← グリッドの一部がゆっくりフェードイン
│    ● ● ● ● ● ● ● ● ●          │     （サンシャイン・ライトグレーがランダムに光る）
│    ● ● ● ● ● ● ● ● ●          │
│                                 │
│    人生は、4,160個の週でできている │  ← SF Pro Rounded, 白, 中央揃え
│                                 │
│         [始める]                 │  ← ゴールドのボタン、画面下部
│                                 │
└─────────────────────────────────┘
```

- 背景: 黒
- グリッドは装飾用（実データなし）でゆっくりフェードイン
- 「始める」ボタンは44pt以上、画面下部中央（Z字視線のゴール位置）
- 自動進行はしない。ユーザーが「始める」を押すまで待つ

**好奇心ギャップ**: 「4,160個の週」という具体的な数字が次への行動を促す

### O01.5 グリッド生成アニメーション（新規・ピーク体験）

**目的**: ピーク・エンドの法則のピーク体験。「自分の人生がここに存在する」という実感。

```
┌─────────────────────────────────┐
│                                 │
│    ○ ○ ○ ○ ○ ○ ○ ○ ○ …       │
│    ○ ○ ○ ○ ○ ○ ○ ○ ○ …       │  ← 上から順に丸が出現していく
│    ○ → ● → ● → ● ...          │     過去の週が左からライトグレー・サンシャインに
│    ...                          │     着色されながら埋まっていく（2〜3秒）
│                                 │
│    ○ ○ ○ ○ ○ ○ ○ ○ ○ …       │  ← 現在地で止まる
│    ← 現在地にソフトホワイトのリング│
│                                 │
│    あなたの人生は                 │
│    1,234週目を迎えています。      │  ← SF Mono で週数を表示
│                                 │
│         [確認する]               │
│                                 │
└─────────────────────────────────┘
```

- アニメーション時間: 2〜3秒（速すぎず遅すぎず）
- 過去週は一括ではなくスキャンするように順番に着色
- 現在週でアニメーションが止まり、ソフトホワイト（#F2F2F7）のリングが輝く
- Reduce Motion が ON の場合: アニメーションなしで最終状態を即時表示
- ハプティクス: アニメーション完了時に `.notificationFeedback(.success)`

### O03 壁紙設定ガイド（任意フロー・格下げ）

- オンボーディングのメインフローから除外
- S01（グリッド画面）初回表示時に **非侵入型バナー**（画面下部に1度だけ表示）で案内
- バナーコピー: 「壁紙を毎週自動更新する設定ができます →」
- バナーをタップ → O03 画面に遷移
- バナーを×で閉じる → 設定画面からいつでもアクセス可能

**変更理由（段階的要請・認知負荷）**
初回起動の感動体験（O01.5）の直後に技術的な設定手順を強要すると離脱リスクが高い。
アプリの価値（グリッドを見る体験）を先に届け、ユーザーが「もっと使いたい」と思ってから提案する。

## 4. S01 グリッド画面（メイン・タブ1）

### レイアウト構成

```
┌─────────────────────────────────┐
│  LIFE IN WEEKS                  │  ← ナビゲーションタイトル（左揃え）
├──┬──────────────────────────────┤
│  ● ● ● ● ● ● ● ● ● …（48列）│
│  ● ● ● ● ● ● ● ● ● …        │  ← 過去週：サンシャイン(avg>4.5) / ライトグレー
│  ● ● ● ● ● ● ● ● ● …        │     未記録週はチャコールグレー（同サイズ）
│  ◎（ソフトホワイトリング：現在週）│  ← 現在位置マーカー（1.5pt リング）
│  · · · · · · · · · …          │  ← 未来週：チャコールグレー・ドット50%サイズ
│  · · · · · · · · · …          │
│                                 │
├─────────────────────────────────┤
│ [カレンダー] [記録] [統計] [設定]│  ← タブバー（4タブ）
└─────────────────────────────────┘
```

### グリッド座標系（人生基準）

グリッドはカレンダー年ではなく**人生を基準**とする。

- 左上 (row=0, col=0) = **誕生週**（誰にとっても最初の丸）
- row = lifeWeekIndex / 52（誕生年が row=0）
- col = lifeWeekIndex % 52（誕生週が col=0）
- 現在週 = `floor((today − birthDate).days / 7)`
- 6月23日生まれなら 1 行目は「6月〜翌5月」で構成される（ISO カレンダー週とは不一致）

### 選択インジケーターの変更履歴

| 項目 | v1.x | v2.0（usertest v2後） | v3.0（現在） | 変更理由 |
|------|------|---------------------|------------|---------|
| 色 | 赤丸 → ゴールドリング | 黄色アウトライン（1.5pt） | ソフトホワイト #F2F2F7（1.5pt） | 黄=サンシャインドットと区別するため白系に変更 |
| 形状 | 丸塗りつぶし | 外側に黄色リング | 外側にソフトホワイトリング | 確実に視認可能なインジケーター |

### 週詳細シートの開き方変更（usertest #11反映）

| 操作 | v2.0 | v2.1（usertest後） | 変更理由 |
|------|------|-------------------|---------| 
| 過去週のタップ | タップ→即時シート表示 | タップ→選択のみ（シートは開かない） | 誤タップで意図せず編集が開くのを防ぐ |
| 週詳細の開き方 | タップ | 選択後にボトムシートのボタンから | 2ステップにして誤操作防止 |
| 今週の記録 | FABボタン | 変更なし | - |
| 未来週 | タップ可能 | タップ不可・薄いグレー表示（usertest #14） | 未来の記録を入力できないようにする |

### 選択週の日付表示（usertest #12追加）

グリッド上部に選択中の週の日付範囲を常時表示する。
- 形式: `2024年1月15日〜21日`（第X週の表記なし）

### FABボタン（usertest v2 #10で廃止）

- **廃止**: FABボタンをGridViewから削除
- 記録はタブバーの「記録」タブから行う

### 「記録」タブ（usertest v2 #10で追加・v3-#5でボトムシートに変更）

- タブバーの2番目: 鉛筆アイコン + 「記録」ラベル
- タップするとカレンダータブのまま `WeekDetailSheet` がボトムシートとして下から表示される
- グリッドでタップした週（`selectedWeekForRecord`）が記録シートに反映される
- 背景のグリッドが見える状態でハーフサイズ表示（`.presentationDetents([.medium, .large])`）
- 下スワイプまたはシート外タップで閉じる

### ライフステージバー（usertest v2 #4で廃止）

- **廃止**: ライフステージバーをGridViewから完全削除
- 統計はタブバーの「統計」タブから直接アクセス可能なため不要
- グリッドが横幅全体に広がり、画面いっぱいにドットを表示（usertest v2 #9）

### スワイプ操作（usertest v2 #5追加・v3-#4で方向修正）

| 操作 | 動作 | 方向の考え方 |
|------|------|------------|
| 右スワイプ | 選択週を+1週（次週）に移動 | スワイプした方向にドットが動く |
| 左スワイプ | 選択週を-1週（前週）に移動 | スワイプした方向にドットが動く |
| 下スワイプ | 選択週を+52週（次年）に移動 | 下=未来方向 |
| 上スワイプ | 選択週を-52週（前年）に移動 | 上=過去方向 |

### 下部統計バー: 廃止

グリッド画面に統計バーは表示しない。グリッドの純粋な視覚体験を損なうため。
人生消費率（31.9%）は S03 統計画面の累計記録セクションに表示する。

### 初回グリッド表示（空の状態設計）

記録がゼロの状態のグリッドは「未来のキャンバス」として演出する。

```
過去の週（未記録）: チャコールグレー（#48484A）
過去の週（記録あり、avg≤4.5）: ライトグレー（#AEAEB2）
過去の週（記録あり、avg>4.5）: サンシャイン（#FFE566）
現在週:   ソフトホワイトリング（#F2F2F7）で強調
未来週:   チャコールグレー・50%サイズの小さいドット

グリッド中央付近に薄いオーバーレイで:
「今週をタップして、最初の記録をつけよう」
（1度でも記録したら表示しない）
```

## 9. エラー状態・例外フロー

### E01 写真ライブラリ権限拒否

壁紙生成アクション（AppIntent）実行時に写真ライブラリ権限がない場合。

```
┌─────────────────────────────────┐
│                                 │
│  ⚠️ 壁紙を保存できません          │
│                                 │
│  写真ライブラリへのアクセスが      │
│  許可されていません。              │
│                                 │
│  [キャンセル]  [設定を開く →]     │  ← 「設定を開く」でiOS設定へ遷移
│                                 │
└─────────────────────────────────┘
```

- 表示タイミング: 壁紙生成ショートカット実行時
- 「設定を開く」: `UIApplication.shared.open(URL(string: UIApplication.openSettingsURLString)!)` でiOS設定を開く
- キャンセル後: 記録データへの影響なし。アプリは継続動作
- 文言トーン: 赤文字・警告アイコンは使わない。オレンジのインフォアイコンで統一

---

### E02 iCloud未接続・未サインイン

iCloudが使えない状態でアプリを起動した場合。

- **表示しない**（サイレント対応）。ローカル保存で継続動作する
- iOSのシステム通知に委ねる（アプリ側で追加通知しない）
- 設定画面に同期状態インジケーターは設けない
- **根拠**: iCloud接続状態の通知は認知負荷を高め、アプリの核心価値（人生の可視化）から注意を奪う。接続が回復した時点で自動同期されるため、ユーザーアクションは不要

---

### E03 ショートカット自動実行の失敗

毎週月曜7時の自動実行がなんらかの理由で失敗した場合（iOS制約・権限切れ等）。

**フォールバック設計**

```
S01 グリッド画面（月曜アプリ起動時）
 └── 前回壁紙更新から7日以上経過している場合
       └── 画面下部に非侵入バナーを1回だけ表示:
           「今週の壁紙がまだ更新されていません」
           [今すぐ更新する →]  ← タップで S05 壁紙設定ガイド へ
```

| 条件 | 判定方法 |
|------|---------|
| 前回更新日時 | `UserDefaults` に `lastWallpaperGeneratedAt: Date` を保存。壁紙生成AppIntent実行時に更新 |
| バナー表示判定 | アプリ起動時に `今日 - lastWallpaperGeneratedAt > 7日` をチェック |
| バナー再表示 | 同じ週は1回のみ（×ボタンで閉じたら `wallpaperBannerDismissedWeek` を記録） |

- バナーを×で閉じた場合: その週は再表示しない
- バナーを「今すぐ更新する」でタップした場合: S05 壁紙設定ガイドに遷移し、手動実行を案内
